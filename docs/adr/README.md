## Regra

Um ADR aceito registra a decisão no contexto da época. Se a decisão mudar,
marque o documento como substituído e crie um novo ADR com referência
bidirecional. Não reescreva o passado para esconder a mudança.

Todo ADR deve conter contexto, decisão, consequências, alternativas e rollback.
